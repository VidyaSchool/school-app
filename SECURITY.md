# Security Policy

## Supported Versions

We actively provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

The VidyaSchool team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose your findings.

### How to Report

If you believe you have discovered a security vulnerability in this repository, please **do not** report it publicly through a GitHub issue. Instead, please follow one of these private channels:

1. **GitHub Private Vulnerability Reporting**:
   - Navigate to the **Security** tab of this repository.
   - Click on **Advisories** -> **Report a vulnerability**.
2. **Email**:
   - Send details to `security@vidyaschool.com` or `admin@vidyaschool.com`.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction steps or a minimal proof-of-concept (PoC).
- Any relevant logs, request payloads, or system details.
- Suggestions for remediation (if available).

### Response Timeline

- **Initial Response**: Within 48 hours of receipt.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Patch Deployment**: We aim to release security patches as expeditiously as possible.

Thank you for helping keep VidyaSchool and its community safe!
